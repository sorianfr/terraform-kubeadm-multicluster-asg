# Ansible Playbooks for Kubernetes Cluster Management

This directory contains Ansible playbooks and roles for managing Kubernetes clusters provisioned by Terraform.

## Structure

```
ansible/
├── inventory/
│   └── hosts.yml              # Inventory file with control plane nodes
├── group_vars/
│   ├── all.yml               # Global variables
│   └── control_planes.yml    # Control plane specific variables
├── roles/
│   └── calico/
│       ├── defaults/
│       │   └── main.yml      # Role defaults
│       ├── tasks/
│       │   └── main.yml      # Main tasks
│       └── templates/
│           └── installation.yaml.j2  # Calico installation template
├── playbooks/
│   └── install_calico.yml    # Playbook to install Calico
├── ansible.cfg              # Ansible configuration
└── README.md                # This file
```

## Usage

### Prerequisites

1. Ensure Terraform has provisioned the infrastructure
2. Ensure the SSH key `k8s-key.pem` (or your custom key name) is available in the terraform directory
3. The Ansible inventory is automatically generated by Terraform during `terraform apply`

### Running the Calico Installation

**Option 1: Run from bastion host (recommended)**
```bash
# SSH to bastion
ssh -i k8s-key.pem ubuntu@<bastion-public-dns>

# Run from bastion
cd ansible
ansible-playbook playbooks/install_calico.yml
```

**Option 2: Run from local machine**
```bash
# From the ansible directory
ansible-playbook playbooks/install_calico.yml

# Or with specific inventory
ansible-playbook -i inventory/hosts.yml playbooks/install_calico.yml

# To target specific cluster
ansible-playbook playbooks/install_calico.yml --limit cluster1_control_plane
```

### Inventory Configuration

The inventory is automatically configured based on the clusters defined in `terraform.tfvars`:

- **cluster1_control_plane**: 10.0.2.10 (pod_network_cidr: 10.244.0.0/16)
- **cluster2_control_plane**: 10.0.3.10 (pod_network_cidr: 10.245.0.0/16)

### Variables

Key variables that can be customized:

- `pod_network_cidr`: Pod network CIDR for each cluster (set per cluster in inventory)
- `bastion_public_dns`: Bastion host DNS name (set in group_vars/all.yml)
- `calico_version`: Calico version to install (default: v3.27.3)

### Connection

The playbooks connect to control plane nodes through the bastion host using SSH proxy commands. Ensure:

1. The bastion host is accessible
2. The SSH key is properly configured
3. The control plane nodes are reachable through the bastion
